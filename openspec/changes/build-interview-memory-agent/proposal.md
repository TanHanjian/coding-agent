## Why

个人刷算法题与准备综合面试时，题目、作答、错因和复盘通常散落在网页、笔记和聊天记录中，难以持续检索、复用和安排复习。本变更建立一个本地优先的 React Web 记忆 Agent，把个人做题过程沉淀为可追溯知识，并通过 Go AI Agent 后端编排、RAG、AI 辅助和间隔重复形成完整学习闭环。

## What Changes

- [MVP] 提供统一题库和题型模板，记录题干、多次作答、结果、错因、复盘、标签、代码块与本地图片。
- [MVP] 提供全文与向量混合检索，基于个人题库回答问题并返回可跳转引用；个人证据不足时，把模型通用知识明确标为“通用补充”。
- [MVP] 支持保存多个 OpenAI 兼容模型端点，独立选择聊天模型和嵌入模型，并管理连接验证与索引重建。
- [MVP] 提供完整本地备份、恢复和 Markdown 导出，确保图片随数据迁移且密钥不会泄露。
- [Phase 2] 提供做题中的分级提示和作答后的 AI 诊断，只有用户确认的 AI 内容才会进入长期记忆。
- [Phase 3] 提供基于 FSRS 的复习队列、四级回忆评分和应用内到期提醒。
- Web 端固定提供仪表盘、题库、题目工作台、RAG 问答、复习队列和设置六个主入口。

### Non-goals

- 首版不提供账号、云同步、多人协作、网页抓取、外部资料库导入或跨设备数据合并。
- 首版不运行用户代码，不提供在线判题或多语言执行沙箱。
- 首版不加密 SQLite 数据库，不提供系统级通知，不同时支持 PostgreSQL 数据源。
- 本变更不包含 design、tasks 或业务代码；这些内容须在需求评审通过后另行产出。

## Capabilities

### New Capabilities

- `question-memory`: 统一管理面试题、题型模板、多次作答、错因复盘、图片附件、题库检索与 Web 工作流。
- `rag-assistant`: 管理模型端点与索引生命周期，基于个人记忆执行混合检索、流式回答和题目级溯源。
- `guided-solving`: 在用户显式请求时提供渐进式提示、作答诊断和可选择保存的改进内容。
- `spaced-review`: 使用 FSRS 管理复习资格、到期队列、回忆评分、进度和应用内提醒。
- `local-data-and-settings`: 管理离线能力、凭据安全、数据备份恢复、Markdown 导出和本地性能约束。

### Modified Capabilities

无。本项目当前没有已发布的 OpenSpec capability。

## Impact

- 产品形态：面向个人用户的本地优先 React Web 应用，界面语言为中文；Go 后端默认在本机运行并由浏览器访问。
- 技术边界：React/TypeScript 负责 Web 界面，Go 负责业务 API 与 AI Agent 编排，SQLite 仅由 Go 后端访问；采用前后端分离的 Web 服务架构。
- 外部系统：用户配置的 OpenAI 兼容聊天与嵌入端点，以及由 Go 后端封装的可替换凭据存储。
- 数据边界：普通学习数据保存在本机；模型调用仍由用户显式触发并仅发送必要上下文。另行明确授权的可选完整 Trace 可上传范围内的完整真实学习内容；默认关闭且与脱敏 Trace 独立配置，配置不代替授权。告知接收方、用途和内容范围，本地记录授权范围、时间和告知版本；撤销停止后续完整上报，已上传不自动删除，接收方、用途或范围变化重新授权。凭据永不上传，原始错误脱敏；普通日志、诊断和 UI 摘要不是授权 Trace 通道。
- 运行恢复：独占本机单进程数据目录；启动接受请求前原子收敛遗留生成为失败并保留文本，不恢复 checkpoint，具体契约见 [Step 4 设计](../step-4-eino-memory-agent/design.md)。
- 评测边界：沿用 [本地评测 MVP](../add-agent-evaluation/design.md)，固定版本及执行身份约束不要求引入第三方平台，也不调整其他里程碑。
- 服务边界：Go 后端 MUST 提供健康检查、题库与会话 API、流式 AI API 和长任务进度 API，并默认仅监听本机地址。
- 后续设计需为 SQLite 数据访问建立可替换边界，以允许未来迁移 PostgreSQL/pgvector，但不得在首版实现双数据库。
