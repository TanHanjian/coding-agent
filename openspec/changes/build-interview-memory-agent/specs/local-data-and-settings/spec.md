## Purpose

该能力确保个人学习记录在没有网络和模型服务时仍可可靠使用，并通过安全凭据、可验证备份恢复、可读导出和明确性能目标保护长期积累的数据资产。

## ADDED Requirements

### Requirement: 本地优先与离线降级
[MVP] 系统 MUST 在 Go 后端管理的本地数据目录中保存题目、作答、复盘、附件、复习状态、索引元数据和所选会话；断网或模型不可用时，除 AI 调用和需要远程嵌入的索引操作外，其余记录与检索管理 MUST 正常工作。

#### Scenario: 离线编辑题目
- **WHEN** 设备没有网络连接且用户创建或编辑题目
- **THEN** 系统正常保存本地记录并允许关键词搜索，不要求登录或连接远程服务

#### Scenario: 离线请求 AI
- **WHEN** 用户在离线状态触发 RAG 回答、提示或诊断
- **THEN** 系统说明所选模型不可达，保留用户输入且不影响本地题库操作

### Requirement: API Key 安全存储
[MVP] 系统 MUST 通过 Go 后端封装的安全凭据存储保存 API Key，业务数据仅保存不可逆推出密钥的凭据引用；完整密钥 MUST 不出现在界面回显、SQLite、附件、日志、导出或备份中。

#### Scenario: 保存 API Key
- **WHEN** 用户为模型档案输入并保存 API Key
- **THEN** 系统将密钥写入安全凭据存储，重新打开设置时只显示已配置状态和掩码

#### Scenario: 删除模型档案
- **WHEN** 用户确认删除模型档案
- **THEN** 系统同时删除对应安全凭据引用和密钥，并保留不依赖该档案的题库数据

#### Scenario: 凭据读取失败
- **WHEN** 安全凭据存储拒绝访问或凭据已丢失
- **THEN** 系统把档案标记为需要重新授权，不得回退到明文配置

### Requirement: 出站数据需要用户动作
[MVP] 系统 MUST 仅在用户显式执行连接测试、索引、RAG 回答、提示或诊断时向配置端点发送数据，并在设置中说明各操作可能发送的数据类别；系统 MUST 不包含默认遥测。

#### Scenario: 普通浏览题库
- **WHEN** 用户浏览、搜索或编辑本地记录且未触发 AI 操作
- **THEN** 系统不向模型端点发送题目、作答或复盘内容

#### Scenario: 查看数据发送说明
- **WHEN** 用户在模型设置中查看隐私说明
- **THEN** 系统列出连接测试、嵌入和聊天操作各自可能发送的内容，并说明接收方是用户配置的端点

### Requirement: 完整备份
[MVP] 系统 MUST 创建带格式版本、创建时间、完整性清单和内容校验信息的本地备份包，包含业务数据和托管图片，但 MUST 排除 API Key、临时文件、缓存和可重新生成的向量索引。

#### Scenario: 创建完整备份
- **WHEN** 用户选择目标位置并执行完整备份
- **THEN** 系统生成可校验的单个备份包，报告包含的题目和附件数量，并保持当前数据可继续使用

#### Scenario: 备份期间存在写入
- **WHEN** 用户在备份创建期间继续编辑记录
- **THEN** 系统生成内部一致的时间点快照，不得产生一半更新的数据关系

#### Scenario: 目标位置不可写
- **WHEN** 备份目标无权限或空间不足
- **THEN** 系统报告失败且不留下被标记为成功的损坏备份

### Requirement: 可恢复且可回滚的还原
[MVP] 系统 MUST 在还原前验证备份格式、版本、完整性和附件清单，明确告知还原会替换当前数据，并在替换前自动创建当前数据的回滚快照；失败时 MUST 恢复原数据。

#### Scenario: 成功还原备份
- **WHEN** 用户确认还原一个兼容且完整的备份包
- **THEN** 系统替换当前业务数据和附件、重新建立可生成索引，并提示 API Key 需要在本机重新配置

#### Scenario: 备份损坏
- **WHEN** 校验发现备份内容缺失或被修改
- **THEN** 系统拒绝还原并保持当前数据不变

#### Scenario: 还原中途失败
- **WHEN** 数据替换或附件恢复过程中发生错误
- **THEN** 系统使用回滚快照恢复还原前状态，并给出可诊断错误

### Requirement: Markdown 导出
[MVP] 系统 MUST 支持导出全部或筛选后的题目为可读 Markdown，保留题目元数据、作答历史、错因、复盘、AI 来源和相对图片引用；导出内容 MUST 不包含凭据或内部索引。

#### Scenario: 导出筛选结果
- **WHEN** 用户筛选某组标签并选择 Markdown 导出
- **THEN** 系统仅导出筛选范围内的题目，为每题生成稳定可读内容，并复制其引用图片

#### Scenario: 导出文件名冲突
- **WHEN** 多道题生成相同的安全文件名
- **THEN** 系统通过稳定后缀避免覆盖，并在导出清单中保持题目与文件的对应关系

### Requirement: 数据格式版本兼容
[MVP] 系统 MUST 为本地数据和备份声明格式版本，并在应用升级或还原旧版本时执行可验证迁移；遇到比当前应用更新且不兼容的格式时 MUST 拒绝写入。

#### Scenario: 首次打开旧版本数据
- **WHEN** 当前应用检测到受支持的旧数据格式
- **THEN** 系统先创建恢复点，再完成迁移并验证关键记录数量和关系

#### Scenario: 打开未来版本备份
- **WHEN** 备份格式版本高于当前应用支持范围
- **THEN** 系统拒绝还原并提示使用兼容版本，不修改现有数据

### Requirement: 本地性能目标
[MVP] 系统 MUST 在包含 10,000 道题及其关联作答和复盘的个人数据集中，使题库关键词搜索和组合筛选在本地运行环境中于 500 毫秒内返回首屏结果；模型生成与远程嵌入耗时不计入该目标。

#### Scenario: 大型题库搜索
- **WHEN** 测试数据包含 10,000 道题且用户执行关键词与三项组合筛选
- **THEN** 从提交查询到首屏结果可交互的时间不超过 500 毫秒

#### Scenario: 远程模型缓慢
- **WHEN** 模型端点响应缓慢但用户同时浏览或搜索题库
- **THEN** 本地题库交互继续响应，不被远程请求阻塞

### Requirement: 写入可靠性
[MVP] 系统 MUST 以原子操作保存题目及其关联关系，并在应用异常退出后恢复到最近一次完整提交，不得留下引用不存在题目、作答或附件的半完成业务记录。

#### Scenario: 保存题目时异常退出
- **WHEN** 应用在题目与其元数据保存过程中异常退出
- **THEN** 下次启动后要么显示完整新版本，要么显示完整旧版本，不显示部分写入状态

#### Scenario: 启动时发现一致性问题
- **WHEN** 系统检测到可恢复的数据或附件一致性问题
- **THEN** 系统停止破坏性写入、说明受影响范围并提供从最近恢复点修复的操作

### Requirement: 数据位置与诊断可见
[MVP] 系统 MUST 在设置中显示业务数据和附件所在位置、当前数据量、备份格式版本和索引状态，并提供打开本地数据目录及复制脱敏诊断信息的操作。

#### Scenario: 复制诊断信息
- **WHEN** 用户选择复制诊断信息
- **THEN** 系统提供应用版本、数据格式、记录数量和错误代码，但不包含 API Key、完整题目正文或个人答案

#### Scenario: 打开数据目录
- **WHEN** 用户选择打开本地数据目录
- **THEN** 系统展示 Go 后端当前使用的精确数据目录，并提供复制路径操作，不暴露其他用户数据
