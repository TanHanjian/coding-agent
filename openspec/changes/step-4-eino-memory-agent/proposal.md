# Proposal

## Why

在现有聊天和题库能力之上，建立可调用题库能力的 Eino Agent，使对话能够检索题目、结合历史作答和复盘，并在用户明确确认后保存新的记忆。

## What Changes

- 支持 Eino Tool Calling 循环、工具调用上限和取消传播。
- 增加题目、作答、复盘的只读检索工具。
- 增加最多一个待确认记忆候选及聊天内确认、拒绝流程。
- 通过已有领域 service 写入题目、作答或复盘。
- 保持现有模型配置方式，不引入模型替换中心。

### Non-goals

- 不实现模型档案和凭据管理。
- 不实现向量索引、Embedding、FSRS 或多用户能力。
